```

```

## 🚀 Publicar en GitHub Pages

1. Crea un repositorio en GitHub (ej. `valen-magical`)
2. Sube todos los archivos de esta carpeta al repositorio
3. Ve a **Settings → Pages → Source: Deploy from a branch → main / root**
4. Tu página estará en: `https://[tu-usuario].github.io/valen-magical/`
5. ⚠️ Actualiza la URL en `index.html` (busca `valenmagical.github.io` y reemplaza con tu URL real)
